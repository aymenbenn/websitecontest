# Auditlab image filenames

Put your real images in `public/images/` using these filenames:

- report.png — homepage hero/sample report
- performance.png — Performance audit
- seo.png — SEO audit
- uiux.png — UI/UX audit
- aeo.png — AEO audit
- ga4.png — GA4 audit
- google-ads.png — Google Ads audit
- afterbefore.png — featured case study / before-after
- case-study.png — secondary case studies
- avatar.png — testimonial portrait
- analytics.png — analytics/dashboard fallback
- dashbored.png — dashboard visual
- audit.png — audit visual
- data.png — data visual
- reports.png — report visual

The React image component now uses these exact paths:
`/images/<filename>`

So you can replace any image with another JPG/PNG, but keep the filename.
